# Java Tic-Tac-Toe

A two-player, command-line Tic-Tac-Toe game built with core Java. Players enter positions from 1 to 9 using a numeric-keypad layout.

## Features

- Two-player local gameplay using `X` and `O`
- Input validation for non-numeric, out-of-range, and occupied positions
- Win detection for rows, columns, and diagonals
- Draw detection when all nine positions are filled
- Replay support after each round
- No external libraries or dependencies

## Technologies

- Java 8 or newer
- `java.util.Scanner` for console input
- Arrays and loops for board and game-state management

## Board Mapping

```text
 7 | 8 | 9
---+---+---
 4 | 5 | 6
---+---+---
 1 | 2 | 3
```

## Run the Project

Open a terminal in this folder and run:

```bash
javac Main.java
java Main
```

The compiled `Main.class` file is generated by `javac`; only `Main.java` is required as source code.

## Java Concepts Demonstrated

- Classes and the `main` method
- Encapsulation through private helper methods
- Constant fields with `static final`
- Arrays, loops, conditionals, and exception handling
- Console input using `Scanner`
